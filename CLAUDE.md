# Claude Vault — Project Memory

## What This Is
This repo IS the `~/Claude/` folder — the centralized hub for all of ranshaked's Claude-related assets on their Mac. The repo name is `promptvault` on GitHub (`ranshaked1/promptvault`), but it lives at `~/Claude/` locally.

## Folder Structure
```
~/Claude/
├── projects/              ← user's automation repos
│   ├── ai-cost-tracker/   ← tracks AI API costs
│   ├── cal-daily-report/  ← daily Google Calendar summaries
│   └── VS Temp folder/    ← VS Code/Cursor experiments
├── configs/
│   ├── claude-code/       ← symlinked from ~/.claude/
│   └── claude-desktop/    ← symlinked from ~/Library/.../Claude/
├── mcp-servers/
├── skills/
├── hooks/
├── scripts/
│   └── youtube_english_filter.py
├── prompts/
├── backups/
├── scanner.py             ← discovers all Claude assets on system
├── migrate.py             ← moves assets + creates symlinks
├── vault.py               ← CLI: scan, list, search, status, catalog, describe, tree, migrate
├── catalog.py             ← generates MY_ASSETS.md from registry + descriptions
├── descriptions.json      ← user-editable one-sentence descriptions (persists across scans)
├── setup_weekly_scan.sh   ← installs macOS launchd weekly scan job
├── registry.json          ← auto-generated scan results (gitignored)
├── MY_ASSETS.md           ← human-readable asset catalog
└── README.md
```

## Key Commands
```bash
python3 vault.py scan                    # scan + regenerate MY_ASSETS.md
python3 vault.py status                  # dashboard
python3 vault.py list [category]         # list assets
python3 vault.py search <query>          # search by name/path
python3 vault.py catalog                 # regenerate MY_ASSETS.md only
python3 vault.py describe <name> <desc>  # add/update description
python3 vault.py tree                    # show folder tree
python3 vault.py migrate plan|execute|verify
```

## Important Notes
- `registry.json` is gitignored (contains local paths, regenerated by scanner)
- `descriptions.json` IS tracked — user's custom descriptions persist
- `MY_ASSETS.md` IS tracked — the readable asset catalog
- Projects in `projects/` are gitignored (each has its own repo)
- Configs with secrets (`.credentials`, `.claude.json`) are gitignored
- The scanner works on both macOS and Linux
- Symlinks mean configs stay at their original paths — nothing breaks
